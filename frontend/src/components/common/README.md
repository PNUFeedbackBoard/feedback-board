# components/common

**이 폴더의 소유자는 D 다.**

## 지금 있는 것

- 색상·타이포그래피·여백 토큰 — `src/styles/tokens.css`. 값은 한 곳에만 정의하고 화면에서
  색상을 직접 쓰지 않는다.
- 상태 배지 4종 — `StatusBadge.jsx`. 접수(파랑) · 처리 중(주황) · 처리 완료(초록) · 반영 불가(회색). 기획 4-2
- 중요도 칩 3종 — `PriorityChip.jsx`. 긴급 · 보통 · 여유. 세 단계를 함께 표시하고 현재 값만 떠오르게 강조한다. 기획 4-3
- 우선 처리 요청 배지 — `PriorityRequestBadge.jsx`. 파란 별 이미지로 표시하며, 붙어 있으면 우선 처리 요청된 항목이다. 기획 4-4

**관리용 화면(`pages/admin/components/`, `admin-tokens.temp.css`)은 아직 이 공용 버전으로
옮겨 오지 않았다.** 그쪽은 이 폴더가 비어 있던 동안 쓰려고 만든 임시 버전이라, 모양과 값이
똑같다 — 통합 단계에서 import 경로만 바꾸면 된다(기획 13-4).

표시 문자열은 직접 쓰지 말고 `src/constants/enums.js` 의 label 을 쓴다.

## 다른 담당이 필요한 컴포넌트가 없을 때

**기다리지 않는다.** 자기 화면 폴더 안에 임시로 만들고 통합 단계에서 D가 공용으로 흡수한다.
이 폴더에 직접 파일을 추가하지 않는다. (기획 13-4)
